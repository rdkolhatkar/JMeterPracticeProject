IMPORTANT NOTES:

* Use these sites only for practice and learning purposes
* Do NOT perform load testing on real production websites without permission
* Avoid load testing real production sites (like Amazon, Flipkart, etc.) without permission—it can be illegal and may block your IP.
* Start with small load and gradually increase users in JMeter
* Always monitor response time, throughput, and error rate

DUMMY LOGIN APIs FOR JMETER (POST REQUEST TESTING)

1. ReqRes Login API
   URL: https://reqres.in/api/login
   Method: POST

Sample Request Body:
{
"email": "[eve.holt@reqres.in](mailto:eve.holt@reqres.in)",
"password": "cityslicka"
}

Details:

* Returns token on successful login
* Returns error if password is missing or incorrect
* Best for practicing success and failure scenarios
